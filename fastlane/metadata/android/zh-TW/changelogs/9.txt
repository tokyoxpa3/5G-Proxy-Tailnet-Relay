- 修正：「立即切換 IP」不再需要先啟動中繼服務。IP 輪替器改為整個 process 共用一個實例，主畫面按鈕可以獨立動作；HTTP `/rotate` 控制 API 仍需要中繼 listener，因為它綁在 Tailscale 位址上
- 修正：切換 IP 後，轉發中的資料連線過去仍綁在舊行動網路閘道，表現為「沒斷線但下載龜速」。現在會在切射頻之前先關閉這些連線，讓客戶端改用新出口重連
- 新增：確認拿到新公網 IP 之後，中繼會透過一個經過 UID 驗證的窄介面 ContentProvider 通知 5G Proxy Pro，讓 Pro 一併清掉自己綁在舊出口的連線；Pro 未安裝或版本較舊時會安靜略過
- 新增：`/status` 回報 `dropped_connections`，可直接從控制 API 驗證輪替是否有清理連線
- 文件：兩份 README 都補上「IP 輪替與中繼的關係」說明

<b>這是配套程式，不是獨立的代理。</b>它需要手機上同時具備兩樣東西：一個 tailnet 用戶端（Tailscale 或相容實作），以及一個監聽 127.0.0.1 的 SOCKS5 代理。缺任何一項，中繼可以啟動，但不會轉送任何流量。

<b>為什麼需要它</b>

Android 同一時間只允許一個 VpnService。Tailscale 開著的時候，SOCKS5 代理程式就無法啟動自己的 VPN。而改用熱點分享又是另一個問題：封包會保留原本的 TTL 與 TCP 指紋，一看就知道不是手機自己發出的流量。

中繼走第三條路。它留在 tailnet 內，接受從手機 Tailscale 位址進來的 TCP 連線，轉交給本機的 SOCKS5 代理。代理再以手機自己的 UID、經由行動網路重新發起每一條連線。整個過程沒有任何流量經過熱點介面。

<b>支援任何本機代理</b>

5G Proxy Pro、Clash、v2rayNG、shadowsocks-android，任何綁定在 127.0.0.1 的都可以。你只需要填連接埠，不必做任何整合。只轉送 TCP，不支援 UDP（包含 QUIC）。

<b>功能</b>

<ul>
<li>把 tailnet 位址進來的 TCP 轉送到本機 SOCKS5 代理</li>
<li>選用的 SOCKS5 認證（使用者名稱與密碼）</li>
<li>受權杖保護的控制 API，可查詢狀態並遠端輪替行動網路 IP</li>
<li>狀態包含監聽位址、活躍連線數、系統網路驗證結果、整機行動數據用量</li>
<li>可設定開機自動啟動</li>
<li>點擊任一欄即可複製已帶入真實位址與權杖的連線資訊、URL 或 curl 指令</li>
</ul>

<b>遠端 IP 輪替</b>

輪替行動網路 IP 等於切換飛航模式。程式依序嘗試下列後端，且會驗證蜂巢射頻真的斷了才回報成功：

<ul>
<li><b>OmniADB-Host</b> —— 選配的配套 App，透過裝置本機的 ADB 通道執行寫死的指令。不需 root、不用搶助理，Wi-Fi 與 Tailscale 也不會斷。</li>
<li><b>WRITE_SECURE_SETTINGS</b> —— 僅在仍吃飛航設定值的舊 ROM 有效。Android 15 與多數廠商 ROM 上只會改設定值、射頻不動；它本身不是一種輪替方法。</li>
<li><b>設為預設數位助理</b> —— 可靠，但啟用期間會取代 Google 助理。</li>
</ul>

三者都沒有時，轉送功能照常運作，只有遠端 IP 輪替不可用。

<b>隱私</b>

沒有廣告、沒有分析、沒有帳號、沒有追蹤。控制 API 由本機產生的權杖保護；<i>/rotate</i> 會切換飛航模式，請勿外流該權杖。

除了你要求它轉送的連線之外的網路行為：當你觸發 IP 輪替時，程式會經由你設定的 SOCKS5 代理查詢 api.ipify.org，以讀取新的公用 IP。

Android 8.0 以上。同一台裝置上有 tailnet 用戶端。一個監聽 127.0.0.1 的 SOCKS5 代理。

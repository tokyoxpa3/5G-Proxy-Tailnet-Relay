테일넷(Tailscale 또는 호환 클라이언트)에 연결된 어떤 기기에서든, 안드로이드 폰에서 실행 중인 SOCKS5 프록시에 접속할 수 있게 해 주는 컴패니언 앱입니다. 트래픽은 집의 인터넷 회선이 아니라 폰의 셀룰러 회선으로 나갑니다.

이 앱은 프록시가 아닙니다. 폰에서 SOCKS5 프록시를 먼저 실행해야 하며, 5G Proxy Pro, Clash, v2rayNG, shadowsocks-android 등 127.0.0.1에 바인딩되는 어떤 프록시와도 동작합니다.

왜 필요한가

안드로이드의 per-app VPN은 UID 단위로 동작합니다. 폰에서 Tailscale이 돌고 있으면 프록시 앱은 VPN에서 제외되어야 셀룰러로 나갈 수 있지만, 제외되는 순간 Tailscale의 tun 인터페이스로 들어오는 연결을 받을 수 없습니다. 이 앱은 VPN 안에 남아 테일넷 주소에서 TCP를 받고, 프록시의 루프백 리스너로 전달합니다. 두 앱이 각자의 UID를 유지하므로 프록시는 계속 셀룰러로 나갑니다.

기능

- 테일넷 주소(tun 인터페이스 + CGNAT 대역)에만 바인딩합니다. 셀룰러나 LAN에는 바인딩하지 않습니다.
- TCP를 설정 가능한 로컬 SOCKS5 업스트림으로 전달합니다(기본 127.0.0.1:1080).
- 선택 사항인 HTTP 제어 API(/status, /rotate)를 베어러 토큰으로 보호합니다.
- 선택 사항인 IP 로테이션: 비행기 모드를 전환해 모뎀이 다시 attach하도록 합니다.

IP 로테이션

셀룰러 IP를 바꾸려면 라디오를 실제로 전환할 수 있는 방법이 하나 필요합니다.

- OmniADB-Host(권장) — 같은 개발자가 제공하는 선택형 컴패니언 앱. 로컬 ADB 셸로 고정된 비행기 모드 명령만 실행합니다. 어시스턴트를 빼앗지 않고, 루트도 PC도 필요 없습니다.
- 기본 디지털 어시스턴트 — 추가 앱 없이 동작하지만 Google 어시스턴트를 대체합니다.
- 일부 구형 ROM에서는 비행기 모드 설정 기록도 동작합니다.

Android 15 이상에서 WRITE_SECURE_SETTINGS만으로는 라디오를 전환할 수 없습니다. 이 권한은 전환 중 Wi-Fi를 유지하는 용도입니다.

제한 사항

- TCP만 지원합니다. 표준 UDP ASSOCIATE가 없어 QUIC, 일부 게임, VoIP는 통과하지 못합니다. 유일한 UDP 경로는 5G Proxy Client가 쓰는 0x04 UDP-in-TCP 확장입니다.
- 테일넷이 연결되어 있어야 하며, 폰은 항상 켜져 있고 신호가 있어야 합니다.
- 모든 클라이언트가 폰의 셀룰러 IP 하나를 공유합니다.

권한

- 인터넷: 프록시로 전달하는 데 사용합니다.
- 알림: 포그라운드 서비스 상태를 표시합니다.
- 사용 정보 접근(선택): /status에 기기 전체 데이터 사용량을 표시합니다.

개인정보

제어 API 토큰은 기기에서 생성되어 로컬에만 저장됩니다. IP 로테이션을 요청할 때만 api.ipify.org로 현재 출구 IP를 확인하며, 그 외에는 어떤 서버로도 데이터를 보내지 않습니다.

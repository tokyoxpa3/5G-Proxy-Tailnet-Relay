- New: a "Start relay automatically after a reboot" checkbox on the main screen, with a one-line note under it. Until now the relay did come back after a reboot, but only as an implicit rule — nothing in the UI said so, and there was no way to refuse it. It starts only when the box is ticked **and** the relay was still running when you shut down, so pressing Stop keeps it stopped
- The checkbox is ticked by default, unlike 5G Proxy Pro and Client: the relay only binds Tailscale addresses and its control API needs a token, and this was already the behaviour before, so switching it off by default would have silently dropped existing setups
- Removed: the control API token was shown twice on the main screen (once under the status line, once in the "tap to copy" section). It now appears once, in the copy section
